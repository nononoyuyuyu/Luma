# Luma

LAN内のスマホ・PCから画像・動画を閲覧・整理できるローカルメディアライブラリです。画像・動画、タグ、認証情報はサーバーPC内に保存し、外部クラウドやCDNは使用しません。

## 機能

- **フォルダ単位の閲覧**：現在のフォルダ直下の画像・動画と子フォルダをカード表示。配下の画像は混在させず、子フォルダを選択して開きます。検索・お気に入りも現在のフォルダ内が対象です。
- **フォルダ階層表示**：画面上部に現在の階層を表示。各フォルダ名を選択すると、その階層へ移動できます。スマホでは横スクロールで確認できます。
- **動画再生**：サムネイルと再生時間を一覧表示。スマホ・PCの標準プレーヤーで再生・一時停止・シーク・音量操作ができ、画像と同じタグ・名前変更・移動・お気に入りに対応します。
- **折り畳み式ツリー**：左側の矢印で各フォルダを開閉。「フォルダ」見出しでツリー全体も折り畳めます。
- **スマホ向けビュアー**：スワイプ、ピンチ拡大、ダブルタップ、拡大中のドラッグ、フィルムストリップ。
- **PC向け操作**：キーボードで画像切替、ホイール拡縮、全画面表示、5秒間隔のスライドショー。
- **軽量表示**：480pxサムネイル、2560pxプレビュー、遅延読み込み、隣接画像の先読み、原画像表示・ダウンロード。
- **整理**：タグ、検索、お気に入り、名前変更、フォルダ作成、複数画像の一括操作。
- **ドラッグ移動**：画像をフォルダカードや左ツリーにドロップして移動。選択中の複数画像にも対応。Windowsではフォルダ自体の移動も可能です。
- **アップロード**：PCは画像・動画ファイルを一覧やフォルダにドロップ。スマホは「ファイルを追加」ボタンで選択。保存先は現在のフォルダまたはドロップ先です。
- **操作のフィードバック**：マウスによるアプリ内ドラッグは独自のポインター操作を使用。ドラッグ中の件数表示・移動先の強調・画面端での自動スクロール・移動完了の反応。ボタン、メニュー、通知にも短いアニメーションを付け、OSの「動きを減らす」設定を尊重します。
- **アクセス管理**：必須のID・パスワード認証、任意のIP/CIDRホワイトリスト。

対応形式：JPEG / PNG / WebP / GIF / AVIF / BMP / TIFF。EXIFの向きを反映します。アニメーションはブラウザ対応の原形式で再生し、TIFFはプレビューに変換します。HEIC、RAW、SVG、PDF、ZIPは対象外です。

動画形式：MP4 / M4V / MOV / WebM。再生可否は端末・ブラウザと動画内のコーデックに依存します。MP4のH.264映像・AAC音声を推奨します。MOVやHEVCなど再生できない組み合わせでは原本をダウンロードしてください。自動変換は行いません。動画のサムネイルは冒頭から再生時間の10%（最大3秒）進んだフレームを採用します。動画のサムネイルはPyAV同梱のFFmpegでローカル生成するため、別途FFmpegを導入する必要はありません。

アップロードは **画像1ファイル64MiB・動画1ファイル1GiB・1回200件まで**。選択画面は通常のファイル選択を使用します。送信前にブラウザで拡張子・サイズ・ファイル先頭の形式情報を確認し、未対応ファイルを除外します。サーバーでも内容を検査し、同名ファイルは上書きしません。ブラウザへのフォルダごとのドロップは対象外です。フォルダごとの追加はサーバーPCの `public` へコピーしてください。

## 導入

主な対象環境は **Windows 10/11・Python 3.11以上**です。Pythonを導入し、`python --version` が使える状態にしてください。

```powershell
git clone https://github.com/nononoyuyuyu/Luma.git
cd Luma
.\start.cmd
```

Gitを使わない場合は「Code → Download ZIP」で取得・展開し、`start.cmd` をダブルクリックします。初回は `.venv` を作成し、`requirements.lock` に固定した依存パッケージを導入します。初回の取得にはインターネット接続が必要ですが、導入後の閲覧はLAN内で完結します。

## 初回設定・起動

1. `start.cmd` を実行します。
2. サーバーPCで **http://localhost:8790** を開きます。
3. 管理者IDと12文字以上のパスワードを設定します。初回設定はlocalhostからのみ行えます。
4. 設定したID・パスワードでログインします。
5. 自動作成される **`public`** に画像・動画・フォルダを入れるか、UIからアップロードします。
6. 同じLANのスマホから **`http://サーバーPCのIPv4アドレス:8790`** を開いてログインします。IPアドレスは `ipconfig` または起動ログで確認できます。

```text
Luma/
  public/                 # 公開する画像・動画。初回起動時に作成
    photo.jpg
    illustrations/
      picture.png
  data/                   # 認証DB・タグ・キャッシュ。非公開
  start.cmd
```

この例の通常一覧には `photo.jpg` と `illustrations` フォルダを表示します。`picture.png` はフォルダを開くと表示されます。

外部からのファイル追加・変更はスキャン終了後15秒の間隔で確認します。コピー中のファイルは次回以降に取り込みます。右上の再スキャンボタンでも実行できます。UIからアップロードした画像・動画は保存後に一覧へ反映します。

### 停止・ポート変更

通常の停止は起動コンソールの `Ctrl+C`。再起動は再び `start.cmd` を実行します。

```powershell
# 別ポートで起動
.\start.cmd --port 8888
# ブラウザを自動で開かず起動
.\.venv\Scripts\python.exe run.py --port 8790
```

同じdataフォルダでの二重起動は拒否します。DBとファイル操作を1プロセスで管理するため、複数workerで起動しないでください。

### スマホから接続できない場合

同じLANに接続し、ゲストWi-Fiの端末間隔離が無効であること、PCがスリープしていないことを確認してください。Windowsのネットワークは「プライベート」に設定します。

ファイアウォールで遮断される場合は、プロジェクトフォルダを管理者PowerShellで開き、以下を1回実行します。

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\allow-lan.ps1
# 別ポートの場合
powershell -ExecutionPolicy Bypass -File .\tools\allow-lan.ps1 -Port 8888
```

プライベートネットワークの同一サブネットから指定TCPポートだけを許可します。ルーターのインターネット向けポート転送は不要です。

## 操作方法

| 操作 | 方法 |
| --- | --- |
| フォルダを開く | カードまたは左ツリーを選択 |
| 上の階層へ | 上部の階層リンク、「上のフォルダへ」、または左ツリー |
| 画像を移動 | 移動先フォルダへドラッグ、情報パネル、または複数選択から移動 |
| フォルダ自体を移動 | Windowsで別フォルダへドラッグ。スマホではカードの「…」から移動先を指定 |
| 画像・動画をアップロード | PCでファイルをドロップ、または「ファイルを追加」で選択 |
| 名前・タグ編集 | 画像の情報パネルで編集して保存 |
| 一括操作 | カードを長押し、または「選択」→タグ・移動・お気に入り。1回200枚まで |
| 動画再生 | プレーヤーの操作ボタン。動画上にフォーカスがある場合は標準のキーボード操作 |
| 画像切替 | 左右キー |
| 拡大縮小 | ホイール、`+` / `-`、`0` でフィット |
| 情報パネル | `I` |
| スライドショー | 再生ボタンまたはスペース。5秒間隔・末尾で停止 |
| ビュアーを閉じる | 閉じるボタンまたは `Esc` |
| 検索 | ファイル名・タグの部分一致。複数タグはAND条件 |

タグは1枚30個、1タグ40文字以内。名前変更・移動は実ファイルに反映します。拡張子変更、同名上書き、フォルダ結合、自身の配下への移動は拒否します。

## 認証・IP制限・HTTPS

**初期状態ではIPフィルタ無効、ID・パスワード認証は常に必須**です。「設定・アクセス管理」からホワイトリストを有効にできます。端末IPまたはCIDRを1行に1つ入力します。localhostは復旧用に常に許可します。

管理者アカウントは1つで、複数端末から利用できます。個別ユーザー・閲覧専用権限はありません。パスワードはsalt付きscryptで保存し、セッションは12時間有効です。CookieはHttpOnly / SameSite=Strict、HTTPSではSecureです。パスワード変更で全セッションを失効させます。

接続元は直接のIPで判定し、転送ヘッダーを信用しません。リバースプロキシ経由は対象外です。URLはIPまたはlocalhostで指定します。

標準起動はHTTPで、通信は暗号化されません。HTTPSはサーバーを停止し、以下のアドレス部分を実際のLAN IPに置き換えて設定します。

```powershell
.\.venv\Scripts\python.exe tools\create_certificate.py --ip <サーバーPCのIPv4アドレス>
.\start.cmd --https
```

接続先は `https://localhost:8790` または `https://サーバーPCのIP:8790`。自己署名証明書なので、各端末で自分のPCが生成した `data/tls/cert.pem` を信頼する設定が必要です。秘密鍵 `key.pem` は共有しないでください。証明書の期限は1年です。ツールは既存鍵を上書きしません。

パスワードを忘れた場合はサーバーを停止し、このPCで対話入力により再設定できます。

```powershell
.\.venv\Scripts\python.exe tools\reset_password.py
```

## 保存・バックアップ

画像は `public`、タグ・お気に入り・認証は `data/library.sqlite3`、プレビューは `data/cache` に保存します。タグはEXIFへ埋め込みません。バックアップはサーバーを停止して `public` と `data` を保存してください。認証DBと秘密鍵を含むため非公開で管理します。

キャッシュはスキャン時に2GiBを目安に整理します。元画像は圧縮・変更しません。破損画像、8,000万画素を超える画像、リンク・ジャンクションは通常の読込対象外です。

UIからの移動は履歴を記録し、中断後は次回スキャンで復旧します。外部リネームもファイルID・サイズ・更新日時が一致する範囲でタグを追跡します。別ドライブへのコピーでは追跡できない場合があります。

## 開発・テスト・公開

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q tests
.\.venv\Scripts\python.exe -m playwright install chromium
.\.venv\Scripts\python.exe tests\browser_smoke.py
.\.venv\Scripts\python.exe tests\benchmark.py
```

テストは合成画像をその場で生成し、`test-results` に隔離します。ユーザーの画像・認証DBは使いません。

**Gitに登録するのはソースと導入文書だけです。** `.gitignore` は許可リスト方式で、画像、`public`、`data`、`.venv`、ログ、テスト成果物、秘密鍵、個人環境の検証レポートを除外します。画像は各自のPCで追加してください。

コミット前に以下を実行すると、ステージされた内容の許可パス・バイナリ・秘密鍵・個人環境の絶対パスなどを検査できます。

```powershell
.\.venv\Scripts\python.exe tools\check_publication.py
```

### UIの動きの設計

操作への反応は130ms、状態変化は220ms、パネル表示は280msを基本にしています。描画負荷を抑えるため主に変形と透明度を使い、動きを減らす設定ではアニメーションを停止します。ドラッグの空白領域は案内を表示し、移動先が指定されなければファイルは移動しません。ブラウザの外側のカーソル表示はOSが制御します。
